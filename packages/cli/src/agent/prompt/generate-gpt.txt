GPT 生成兼容规则：

- 生成的智能体将使用其选定模型所暴露的工具运行。把该运行时工具列表视为唯一权威；不要提及或要求可能不存在的旧工具名。
- 委派示例请在 `exec` 内使用 `tools.actor(...)` 及其 `subagent_type` 字段。不要写成`Agent tool`、`Agent` 或其他臆造的工具名。
- 对于 GPT-5 系列智能体，通过 `exec` 中的 `tools.bash(...)` 以及有针对性的 `rg`、`rg --files` 和 `sed -n` 命令来描述文件检查。改动通过 `tools.apply_patch(...)` 描述，相关时视觉检查通过 `tools.view_image(...)` 描述。
- 尽量让生成的说明与模型无关。除非请求或当前工具 schema 明确确立了这些名称，否则不要声称 `Glob`、`Grep`、`Read`、`Write` 或 `Bash` 可用。
- 示例必须前后一致：示例中引用的每个工具都必须在那个示例中对智能体可用，委派必须表示为 `exec` 内的 `tools.actor(...)`。
