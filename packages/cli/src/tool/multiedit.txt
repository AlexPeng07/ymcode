这是一个在一次操作中对单个文件进行多处编辑的工具。它构建在 `edit` 工具之上，允许你高效地执行多个查找替换操作。当你需要对同一文件做多处编辑时，优先使用此工具而非 `edit` 工具。

使用此工具之前：

1. 使用 `read` 工具了解文件的内容和上下文
2. 核实目录路径正确

要进行多处文件编辑，请提供以下内容：
1. file_path：要修改的文件路径。
2. edits：要执行的编辑操作数组，每个编辑包含：
   - old_string：要替换的文本（必须与文件内容精确匹配，包括所有空白和缩进）
   - new_string：用于替换 old_string 的编辑后文本
   - replace_all：替换 old_string 的所有出现处。此参数可选，默认 false。

重要：
- 所有编辑按提供的顺序依次应用
- 每个编辑都基于前一个编辑的结果
- 所有编辑都必须有效，操作才会成功——任何一个编辑失败，都不会应用任何编辑
- 当需要对同一文件的不同部分做多处修改时，此工具最理想

关键要求：
1. 所有编辑遵循与单个 `edit` 工具相同的要求
2. 编辑是原子的——要么全部成功，要么全部不应用
3. 仔细规划编辑，避免顺序操作之间发生冲突

警告：
- 如果 edits.old_string 与文件内容不完全匹配（包括空白），工具将失败
- 如果 edits.old_string 与 edits.new_string 相同，工具将失败
- 由于编辑按顺序应用，请确保较早的编辑不会影响后续编辑要查找的文本

进行编辑时：
- 确保所有编辑产生符合习惯、正确的代码
- 不要让代码处于损坏状态
- 仅在用户明确要求时使用 emoji。除非被要求，避免在文件中添加 emoji。
- 使用 replace_all 在整个文件中替换和重命名字符串。例如想重命名变量时，这个参数很有用。

如果你想创建新文件，请使用：
- 新的文件路径，必要时包含目录名
- 第一个编辑：old_string 留空，新文件内容作为 new_string
- 后续编辑：对已创建内容进行普通编辑操作
