将文件写入本地文件系统。

用法：
- `file_path` 参数指定要写入的文件。
- 如果所给路径上已存在文件，此工具会覆盖它。
- 如果是已有文件，建议先使用 Read 工具读取，这样你覆盖的是有意保留的内容，而不是过时的猜测。
- 始终优先编辑代码库中已有的文件。除非明确要求，绝不要创建新文件。
- 绝不主动创建文档文件（*.md）或 README 文件。仅在用户明确要求时创建文档文件。
- 仅在用户明确要求时使用 emoji。除非被要求，避免在文件中写入 emoji。
- 对于大文件，建议分多个较小的步骤写入内容，而不是一次巨大的调用：单次超大写入可能超出输出限制而被截断，导致文件不完整或损坏。先用此工具写入初始部分，然后用后续 Edit 工具调用补充其余章节。
