替换、插入或删除 Jupyter notebook（.ipynb 文件）中的单个单元格。

用法：
- 建议先使用 Read 工具读取 notebook，使单元格 id 和内容与磁盘当前内容匹配。工具在应用时仍会加载并校验 notebook。
- `notebook_path` 指定要编辑的 `.ipynb` 文件。
- `cell_id` 是 Read 工具 `<cell id="...">` 输出中显示的 `id` 属性。`replace` 和 `delete` 需要它。对于单元格没有真实 `id` 的旧版 notebook（nbformat_minor < 5），可以传入 `#0`、`#1` 等位置引用（从 0 开始的索引）。首次编辑时，缺失的 id 会自动生成，notebook 会升级到 nbformat_minor 5。
- `edit_mode` 默认为 `replace`。使用 `insert` 在指定 `cell_id` 的单元格之后添加新单元格（如果省略 `cell_id`，则添加到 notebook 开头）——插入时必须提供 `cell_type`。使用 `delete` 删除单元格。
- 对于 `replace`，除非显式提供 `cell_type`，否则保留单元格类型。
- `new_source` 是单元格的完整新内容（`replace` 和 `insert` 必需，`delete` 时忽略）。
- 此工具理解 Jupyter notebook 的单元格结构，并就地修改单元格——处理 `.ipynb` 文件时优先用它而非 Write / Edit，以保持周边 JSON、输出和元数据完整。
