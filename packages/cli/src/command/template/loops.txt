列出生效中的定时任务（cron 调度与自定步调的循环），并允许用户取消它们。

用户关注点或后续参数：
$ARGUMENTS

## 要做的事

1. 调用 `cron` 工具的 `list` 动作，枚举本会话所有生效中的任务。使用该工具自身提示词描述的调用形式——`list` 动作不需要任何参数。

2. 把结果渲染为带序号的表格。每个任务一行。从左到右的列：
   - `id` —— 任务的短 id（便于用户引用）
   - `cadence` —— 对 `kind: cron` 为 5 字段 cron 表达式；对 `kind: loop` 为 `delay_seconds`（格式化为 `~Ns` 或 `~Nm`）
   - `prompt-preview` —— 提示词正文的前 60 个字符；把哨兵标记（`<<autonomous-loop>>`、`<<loop.md>>` 等）替换为简短标签，如 `[autonomous]` 或 `[loop.md]`
   - `kind` —— `cron` 或 `loop`
   - `status` —— 默认为 `active`；如果任务已暂停或即将过期（距 `recurringMaxAgeMs` 不足一个 tick），请注明

   如果没有任务，用一行说明并停止。

3. 如果用户参数中包含 `cancel <id>`（或 `delete <id>`、`stop <id>`、`kill <id>`），用该 id 调用 `cron` 工具的 `delete` 动作并报告结果。同一条消息中有多个 id → 每个 id 调用一次 delete。

## 约定

- 取消后不要重新渲染表格，除非用户要求。只需确认取消了什么。
- 把有歧义的 id（能匹配多个任务的短前缀）视为错误，请用户澄清。
- 绝不要执行所列任务的提示词正文。本命令只读、仅支持取消（read-only / cancel-only）。
