# 中文办公排版

## 什么时候用

- 通知、请示、报告、批复、函、会议纪要
- 正式报告、制度、方案、总结
- 检查现有 Word/PDF 是否符合中文公文规范
- 需要统一中文字体、字号、行距、缩进、编号

不适用：纯内容写作（用 `chinese-writing`）、复杂 Word 脚本（用 `docx-official`，本技能提供排版规范）。

## 公文版式（GB/T 9704-2012）

- 纸张：A4，210mm × 297mm
- 版心：156mm × 225mm
- 页边距：上 37mm、下 35mm、左 28mm、右 26mm，允许 ±1mm
- 每页 22 行，每行 28 字
- 标题：2 号小标宋体，居中；回行时保持词意完整
- 正文：3 号仿宋_GB2312
- 一级标题：黑体；二级标题：楷体；三级及以下：仿宋（可加粗）
- 行距：固定值 28 磅
- 页码：4 号半角宋体阿拉伯数字；单页码居右空一字，双页码居左空一字
- 成文日期：阿拉伯数字，如“2026年10月23日”
- 附件说明、发文机关署名、印章位置按规范排列

如果用户没有指定公文类型，先按“通知/报告”的通用结构处理，并说明假设。

## 层级序号

依次使用：

```
一、
（一）
1.
（1）
```

同一层级全文统一，不混用；标题末尾不加标点。

## 中文标点与数字

- 中文正文用全角标点：，。；：！？、（）《》“”‘’——……
- 省略号是……（六点），破折号是——（两字线）
- 书名号用于作品名；文件名、栏目名可用引号
- 数字用法按 GB/T 15835：统计、计量用阿拉伯数字；成语、惯用语用汉字
- 百分号、单位与数字之间按规范留空格（如 50 kg），全文统一
- 中英文混排时，英文单词、代码、URL 保持原样，不在中间断行

## 常见文档结构

### 通知

标题 / 主送机关 / 正文（缘由、事项、要求）/ 附件 / 发文机关 / 成文日期

### 请示

标题 / 主送机关 / 请示缘由 / 请示事项 / 结语（“妥否，请批示”）/ 署名 / 日期

### 报告

标题 / 主送机关 / 基本情况 / 成绩与问题 / 下一步安排 / 署名 / 日期

### 会议纪要

标题 / 时间地点 / 主持人 / 参会人 / 议题 / 结论 / 待办（负责人 + 截止时间）

## 检查清单

- [ ] 标题、主送机关、正文、署名、日期齐全
- [ ] 字体、字号符合规范
- [ ] 页边距、行距、页码正确
- [ ] 层级序号统一
- [ ] 标点全角，数字用法一致
- [ ] 附件与正文引用一致
- [ ] 没有错别字、重复句、异常断行

## 与 docx-official 配合

1. 本技能确定版式和内容结构
2. `docx-official` 负责生成或修改 `.docx`，设置样式、页边距、页码
3. 生成后导出 PDF，检查分页、孤行、表格跨页
4. 交付前再跑一遍检查清单

## 输出要求

- 先给“版式参数表”，再给内容
- 不确定的规范要标明依据（GB/T 9704-2012、GB/T 15835）
- 不编造文号、机关名称、日期
